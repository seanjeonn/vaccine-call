# W1 음성 대화 PoC — 검증 결과

> 상태: **1차 측정 완료 (로컬)** — 루프 완주 확인, Vercel 실측은 미진행
> 관련: 이슈 #4, PRD 마일스톤 W1, 브랜치 `feature/poc-voice-loop`

## 1. 목적

브라우저에서 한국어 턴제 음성 대화(STT → LLM → TTS)가 실제로 성립하는지, 그리고 지연·품질이 데모로 쓸 만한지 검증한다. 이 루프가 성립해야 F1(AI 모의 사기 훈련)·F3(통화 코파일럿)이 가능하다.

## 2. 검증한 스택

| 컴포넌트 | 채택 | 구현 위치 |
| --- | --- | --- |
| 프레임워크/호스팅 | Next.js 16 (App Router) + Vercel | 루트 앱 |
| STT | OpenAI `gpt-4o-mini-transcribe` (`language: ko`) | `app/api/stt/route.ts` |
| LLM | OpenAI `gpt-4o` (max_tokens 400) | `app/api/chat/route.ts` |
| TTS | OpenAI `gpt-4o-mini-tts` (voice `onyx`, 사기꾼 톤 instructions) | `app/api/tts/route.ts` |
| 녹음 | MediaRecorder (`audio/webm`) | `app/page.tsx` |

OpenAI 키 하나로 STT/LLM/TTS를 모두 처리한다. 서버 API 라우트가 키 프록시 역할을 하며, 각 컴포넌트는 라우트 1개 교체로 스왑 가능하도록 설계했다.

## 3. 측정 방법

`.env.local`에 `OPENAI_API_KEY` 입력 → `npm run dev` → 데스크톱 Chrome에서 폰 프레임 데모의 마이크 버튼으로 연속 대화. 각 턴의 STT/LLM/TTS/합계 지연은 화면 우측 하단 패널에 ms 단위로 표시된다. 아래는 로컬 4턴 실측. (Vercel Preview URL 실측은 미진행.)

## 4. 측정 결과

### 4.1 턴 지연 (ms) — 목표 ≤ 4000, 허용 ≤ 7000

| 환경 | 턴 | STT | LLM | TTS | 합계 |
| --- | --- | ---: | ---: | ---: | ---: |
| 로컬 | 1 | 1995 | 2171 | 4114 | **8280** |
| 로컬 | 2 | 930 | 2250 | 2890 | **6070** |
| 로컬 | 3 | 1926 | 2627 | 4013 | **8566** |
| 로컬 | 4 | 833 | 1736 | 2737 | **5306** |
| **평균** |  | 1421 | 2196 | 3439 | **7056** |

- **합계**: 평균 7056ms. 목표(≤4000) 미달, 허용(≤7000)은 4턴 중 2턴(턴2·4)만 충족. 짧은 발화·짧은 응답 턴이 빠르다.
- **병목은 TTS**: 평균 3439ms로 전체의 약 49%. 이어 LLM 2196ms(31%), STT 1421ms(20%).
- STT·TTS 지연은 각각 발화 길이·응답 길이에 비례해 변동(STT 833~1995, TTS 2737~4114).

### 4.2 한국어 STT 정확도

- 4턴 데모 대화에서 인식 양호 — 대화가 자연스럽게 이어짐 (사용자 확인).
- 정식 10문장 카운트 측정은 미진행. `gpt-4o-mini-transcribe` + `language: ko`로 데모 수준 품질 확보.

### 4.3 한국어 TTS 품질

- 음성 재생·자연스러움 양호 (사용자 확인). voice `onyx` + 사기꾼 톤 instructions 적용.
- 사기꾼 톤 반영 정도의 정성 평가는 W2에서 보강.

### 4.4 기기 호환

- 데스크톱 Chrome: 4턴 연속 대화 완주 성공 (마이크 권한 → 녹음 → STT → LLM → TTS 재생).
- 실기기(iOS/Android)는 계획상 범위 외 (데스크톱 폰프레임 데모 전략).

## 5. 판정

**핵심 가정 검증 성공: 브라우저 한국어 턴제 음성 대화는 성립한다.** STT/LLM/TTS 전 구간이 데모로 쓸 만한 품질로 완주했다. 다만 **지연이 유일한 미달 항목** — 평균 7초로 목표(4초)에 못 미치고, 긴 턴은 허용선(7초)도 초과한다. 병목은 TTS.

- [x] 루프 성립 + 품질 확보 → F1을 **음성으로 진행 확정**
- [ ] STT 미달 → (해당 없음) 필요 시 `gpt-4o-transcribe` 승격
- [ ] TTS 품질 미달 → (해당 없음) 필요 시 ElevenLabs / Clova Voice
- [x] **지연 미달 → W2에서 최적화 필요** (아래 후속 과제)

**결론:** F1(모의 사기 훈련)을 음성 루프로 진행한다. 스택은 OpenAI STT/LLM/TTS + Next.js/Vercel로 확정하되, 체감 지연을 목표(~4초)까지 줄이는 최적화를 W2 우선 과제로 둔다. 현재 지연으로도 데모 시연은 가능하다.

## 6. 미해결 리스크 / 후속 과제

- **지연 최적화 (최우선)**: TTS가 병목(평균 3.4초). ① LLM 스트리밍 + 문장 단위 TTS 파이프라이닝(첫 문장이 나오면 바로 합성·재생 시작 → LLM·TTS 구간 중첩) → **7절에서 적용 완료**, ② 사기꾼 응답을 더 짧게(1~2문장, max_tokens 축소)해 TTS 시간 단축, ③ 필요 시 더 빠른 TTS(`tts-1`) 비교.
- **Vercel 실측 미진행**: 배포 후 네트워크 왕복 포함 지연 재측정 필요. 서버리스 콜드스타트 영향도 확인.
- **정식 품질 측정 미진행**: STT 10문장 정확도 카운트, TTS 자연스러움/톤 정성 평가.
- **훈련 UX**: 현재는 수동 턴 종료(버튼). 실사용엔 무음 감지(VAD)나 "생각 중" 추임새로 대기 체감 완화 검토.

## 7. 2차 측정 — 스트리밍 + 문장 단위 TTS 파이프라이닝 (2026-07-29)

6절 후속 과제 ①을 적용했다. `/api/chat`을 스트리밍으로 바꾸고, 문장이 완성될 때마다 TTS를 먼저 태워 순서대로 재생한다. 전체 응답을 기다리지 않으므로 **첫 소리까지의 시간**이 줄어든다. (이슈 #12)

### 7.1 측정 방법

로컬 `npm run dev` + 데스크톱 Chrome. 1차 측정과 달리 **STT 응답을 고정 텍스트로 스텁**하고(마이크는 합성 스트림) LLM·TTS·재생은 실제 경로를 태웠다. STT 변동을 제거해 LLM+TTS 구간만 같은 조건으로 비교하려는 목적이다. 따라서 아래 수치는 1차 측정의 절대값과 직접 비교하지 말 것 — **같은 날 같은 방식으로 잰 적용 전/후 비교**만 유효하다.

지표 정의도 바뀌었다: **합계 = 턴 시작 → 첫 음성이 실제로 재생되기 시작할 때까지**. LLM은 첫 문장이 완성되기까지, TTS는 그 문장의 합성 시간.

### 7.2 결과 (ms)

| 적용 | 턴 | STT | LLM | TTS | 합계 |
| --- | --- | ---: | ---: | ---: | ---: |
| 전 | 2 | 4 | 1516 | 2424 | **3944** |
| 전 | 3 | 5 | 2636 | 2733 | **5374** |
| **전 평균** | | | | | **4659** |
| 후 | 2 | 4 | 812 | 1455 | **2271** |
| 후 | 3 | 4 | 1167 | 1707 | **2878** |
| 후 | 4 | 5 | 854 | 1742 | **2601** |
| **후 평균** | | | | | **2583** |

- 첫 소리까지 **평균 4659 → 2583ms (약 45% 단축)**. 측정한 3턴 모두 목표(≤4000ms)를 밑돈다.
- LLM 구간이 크게 줄었다(2076 → 944ms 평균). 전체 응답 대신 첫 문장만 기다리기 때문.
- TTS 구간도 줄었다(2579 → 1635ms 평균). 응답 전체가 아니라 첫 문장만 합성하기 때문.

### 7.3 남은 것

- **배포 환경 실측 미진행**: 위는 모두 로컬. 네트워크 왕복·콜드스타트가 더해진 값은 별도 측정이 필요하다.
- **실제 마이크 기준 5턴 측정 미진행**: STT를 스텁했으므로 STT 구간(1차 측정 평균 1421ms)이 실사용에서는 그대로 더해진다.
- 두 항목 모두 이슈 #12에 남아 있다.
